# WebOS - Hack the Web (Bug Hunt)

A tiny operating system that runs in your browser. Beta testers found **6 bugs** (Easy, Medium and Hard) and reported them in the **Issues** tab. Your team picks issues, fixes them and earns points.

## Run it
Open `index.html` in a modern browser. No install needed. Keep DevTools open (F12)!

## Files
- `index.html` - structure
- `style.css` - looks
- `app.js` - all the logic (fix things here)

## How to play
1. **Fork** this repo to make your own copy.
2. Read the issues in the **Issues** tab and pick one.
3. Reproduce the bug in your browser, find the cause in `app.js` and fix it.
4. Open a **pull request** to this repo. In the description write what the bug was, why it happened and how you fixed it, and add `Fixes #<issue number>`.

## Points
| Difficulty | Points per issue |
| ---------- | ---------------- |
| Easy       | 10               |
| Medium     | 25               |
| Hard       | 50               |

## Rules
- One pull request per issue.
- Only fix the bug. Do not change how the app looks.
- A fix counts only if you can (1) reproduce the bug, (2) explain the cause and (3) show that it is fixed.
- Test everything after your fix: every app, every terminal command, refresh the page, close and reopen things. If your fix breaks something else, it will not count.

Happy hunting!
